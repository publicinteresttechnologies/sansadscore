# Commons Score

Commons Score is a UK MP public-record ranking project.

It scores visible, source-backed public work using official and public records. It is not an endorsement, voting recommendation, or claim about private intent.

## Current scope

Commons Score focuses on UK Members of Parliament and currently uses public-record evidence such as:

- UK Parliament Members API
- Written Questions
- Oral Questions
- Commons Votes
- Committees
- Bills
- Register of Members’ Financial Interests
- IPSA public-cost source discovery
- MP website/contact discovery
- GDELT media discovery

## Core rule

No source, no score.

Media and MP websites are treated as discovery or self-claim evidence unless confirmed by official or parliamentary sources.

## Current model

The public score is built around four visible metrics:

- Constituency Work
- Parliamentary Work
- Delivery Track
- Public Value

Local conditions outside an MP’s control should not directly raise or lower the score. Local context should be used only to assess whether visible MP activity matches constituency need.

## Source audit

The data pipeline records a source audit so the public record can show:

- sources used in score
- diagnostic-only sources
- context-only sources
- discovery-only sources
- sources considered with no match
- sources skipped in fast mode
- failed or TODO sources

## Generated data

The files in `data/` are generated by the updater workflow. Do not hand-edit MP rankings or source records. Run the updater instead.

Manual validation:

```bash
python -m py_compile scripts/update_uk.py scripts/commons_score/*.py
```
