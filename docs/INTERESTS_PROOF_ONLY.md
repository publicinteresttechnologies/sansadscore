# Interests API Proof-only rule

Interests API records affect the Proof metric only.

Rules:

- Interests API records increase official source completeness when present.
- Interests API categories are exposed for Sources & Methods.
- Interests are not scored as Activity, Local Focus, Delivery or Public Value.
- The number or category of declared interests is not treated as guilt or virtue.
- No penalty is applied for the content of a declared interest.
