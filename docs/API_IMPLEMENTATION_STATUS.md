# API Implementation Status

This branch adds the non-Lords UK Parliament Developer Hub APIs into code-level inventory.

It does not claim every API is fully scored or fully collected.

## Added to inventory

- Members
- Interests
- Commons Votes
- Oral Questions
- Statutory Instruments
- Treaties
- Erskine May
- Parliament Now
- Bills
- Written Questions
- Committees

## Excluded

- Lords Votes
- Lords-specific interests/endpoints

## Rule

Missing or partial APIs must remain visible in Sources & Methods as tracked sources, not silently absent.
